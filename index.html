Yeeps Note Extractor

MusicXML → Yeeps Paint + Note Block & Delay Block list. No server upload (local browser client-only processing).

Limitations (read before converting)
  • Note grid — choose 8th, 16th, 32nd, or 64th. Yeeps max onset rate is 1200/min (1 wire space). Conversion is blocked if any onset misses the selected grid, or if follow-tempo marks exceed that grid’s 1-space max ♩.
  • Capability (♩ at 1 space) — finer grids need slower tempos:
    GridMax ♩ (1 space)Example at 2 spaces
    8th600300
    16th300150
    32nd15075
    64th7538
    Formula: ♩ = round(1200 / (N × spaces)) where N is notes per quarter (2 / 4 / 8 / 16).
  • No tuplets — triplets, quintuplets, etc. that miss the 64th grid are blocked; simplify the score first.
  • Grace notes are skipped — they are ignored and do not produce note blocks.
  • Tied notes — only the start of a tie is an onset; continuations are not repeated (intended for Yeeps).
  • Simple scores — score-partwise MusicXML from MuseScore-style exports. No repeat/ending expansion, no timewise scores.
  • Pitch range — only pitches covered by Yeeps paints map; others show as No Paint.
  • Tempo — Yeeps patterns are keyed by quarter-note BPM for the selected grid. Metronome markings in other units (e.g. ♪ = 120) are converted to ♩ before snapping.
  • Tempo changes — followed only when “follow tempo changes” is checked. Each numeric metronome or sound tempo snaps to the nearest Yeeps tempo for the selected grid. Leave it unchecked to keep the dropdown tempo for the whole piece. Ritardandi and other text marks without a number are ignored.
